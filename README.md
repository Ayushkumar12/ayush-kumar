# Ayush Kumar - Tech Portfolio

A modern, high-performance portfolio website built with React, Vite, and Framer Motion. This project features a futuristic "Tech" theme with neon accents, glassmorphism, and responsive grid layouts.

## 🚀 Tech Stack

- **Frontend:** React 18
- **Build Tool:** Vite
- **Styling:** CSS Modules, Modern CSS Variables
- **Animations:** Framer Motion
- **Icons:** Lucide React

## 🎨 Theme "Cyber-Tech"

The design system is built around a dark mode aesthetic with:
- **Primary Background:** Deep Black (`#050505`) with grid overlay.
- **Accent Color:** Neon Cyan (`#00f3ff`).
- **Typography:** `Inter` for body text, `JetBrains Mono` for code/tech elements.
- **Components:** Glassmorphism cards with glowing borders and hover effects.

## 📂 Project Structure

```
src/
├── components/
│   ├── About.jsx       # System Overview section
│   ├── Contact.jsx     # Terminal-style contact form
│   ├── Hero.jsx        # Landing section with scanline effects
│   ├── Navbar.jsx      # Glassmorphism navigation
│   ├── Projects.jsx    # Project showcase with holographic cards
│   └── Skills.jsx      # Tech stack visualization
├── App.jsx             # Main application layout
├── index.css           # Global design system & variables
└── main.jsx            # Entry point
```

## 🛠️ Getting Started

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Run Development Server:**
   ```bash
   npm run dev
   ```

3. **Build for Production:**
   ```bash
   npm run build
   ```
